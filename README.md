# Flowie_Android_App
Flowie is a modern Android app that helps users find, rate, and share free water sources across Vienna.

Description:
Flowie is a mobile app that helps people find nearby drinking water sources and stay hydrated on the go. It shows fountains and refill spots on an interactive map, lets you filter by things like active/inactive status and accessibility (wheelchair, dog bowl), and gives quick navigation to a chosen spot. Users can save favourite places locally, track hydration and steps in their profile, and contribute new community water spots with an address, status, optional photo, and location chosen via a centre-pin map.
